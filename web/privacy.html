Privacy Policy

Billed is a browser extension that reconstructs your billable hours. It is built so that the honest answer to "where does my data go?" is "nowhere". This policy says so in detail, and the extension ships as readable source so you can check.

The short version

  • All data stays in your browser profile on your own device.
  • There is no account, no login, no server and no analytics.
  • The developer cannot see your data, and has no way to request it.
  • Uninstalling the extension removes the data with it.

What is stored

For each period of activity in a work-related tab, Billed stores:

  • the domain, for example acme.atlassian.net;
  • the path, for example /browse/PAY-2214;
  • the page title, as shown in the tab;
  • a start time and an end time.

It also stores the clients, rules and settings you create, and — if you buy Pro — your licence key. All of it lives in local browser storage (chrome.storage.local and IndexedDB).

What is never stored

  • Query strings and URL fragments are stripped before anything is written, because that is where search terms, session tokens and record identifiers live.
  • Page contents, form fields, passwords and keystrokes. Billed installs no content scripts, so it has no access to the inside of any page.
  • Screenshots, audio, video or clipboard contents.
  • Anything from a blocked site. Blocked patterns are filtered before storage, not after.
  • Anything from an Incognito window, unless you explicitly allow the extension there.

Billed ships with patterns for banking, health, adult and personal-social sites already on the never-track list, and you can add or remove any pattern at any time.

Network activity

A fresh installation of Billed holds no network permission at all and makes no requests. There is exactly one exception, and it requires your explicit consent:

  • If you buy Pro and paste a licence key, Billed asks Chrome for permission to contact the licence server (api.gumroad.com) and sends only that key, so the purchase can be verified. No activity data is ever included. Decline the permission and the extension keeps working on the free plan.

Once activated, the key is re-checked about once a week for as long as the permission remains granted. You can revoke it in Chrome's extension settings, or remove the licence from inside Billed, at any time.

Permissions, and why each one exists

  • tabs — to read the domain, path and title of the tab you are actively using. This is what makes reconstruction possible; no other permission can provide it.
  • idle — to stop the clock when you step away, so idle time is never billed.
  • alarms — to save progress once a minute, so a browser restart cannot lose your session.
  • storage and unlimitedStorage — to keep your history on your device rather than in a cloud.
  • notifications (optional) — only if you switch on the weekly review reminder.

Billed requests no host permissions at install time and injects no code into any website.

Your control

  • Pause or stop tracking whenever you like; recording stops immediately.
  • Block any domain, subdomain or path so it is never recorded again.
  • Delete a single site's history, a single timesheet line, or everything at once.
  • Set a retention window so older activity is removed automatically.
  • Export a complete backup as one JSON file, on any plan, at any time.

Payments

Purchases are handled by our payment provider, which acts as merchant of record and processes your name, email and payment details under its own privacy policy. Billed never sees or stores your card details. The only thing that comes back into the extension is your licence key.

Children

Billed is a professional tool and is not directed at children under 13.

Changes

If this policy changes in a way that affects what is stored or transmitted, the change will be described in the extension's release notes as well as here, with an updated date at the top.

Contact

Questions about this policy: support. Because there is no server, a data-deletion request is something you carry out yourself in one click — but if you would like help doing it, get in touch.
